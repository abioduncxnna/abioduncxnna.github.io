About

I'm an Implementation Analyst at OyaSync/Fetolsa, where I help hospitality and retail businesses move onto the Fetolsa platform and run it with confidence. My clients include restaurants, lounges, hotels and gas plants, often with several outlets each.

I handle the full implementation: POS and HQ configuration, menu and stock data, printers and network, test runs and staff training. I also write the user guides that keep teams self-sufficient, and I stay close to clients after launch so problems get fixed fast.

I enjoy the point where technology meets daily operations, because that's where a good setup makes a visible difference to a business.

How I implement

  1. Discovery

    Understand the outlets, menus, roles and daily routines, so the system is set up around how the business actually runs.

  2. Configuration

    Set up HQ and POS: menus, prices, taxes, users and permissions, and printer routing.

  3. Data preparation

    Clean and load menus, stock items and prices, so the system starts with accurate data.

  4. Hardware and network

    Install and test printers, terminals and network connections before go-live.

  5. Test run and training

    Run real scenarios end to end, then train staff by role with clear user guides.

  6. Go-live and support

    Be on hand at launch, resolve issues quickly, and hand over documentation.
